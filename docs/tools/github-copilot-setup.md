# GitHub Copilot CLI Setup Guide

The `install_github_copilot.py` script has been moved to a private repository and is no longer available in this public repository.

If you need access to the installer, use your organization’s private repository and internal onboarding process.

This repository now ships a native `agent.md` file at the repository root.
That file follows the Agency/GitHub Copilot-compatible skill format and is the
canonical source of truth for the project's verified capabilities, current bugs,
and roadmap. The published docs mirror is `docs/agent.md`.
